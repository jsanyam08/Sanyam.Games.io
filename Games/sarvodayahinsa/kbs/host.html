🔐 Host Accounts

You are signed in as —.

To let someone host from another laptop, create an account for them and add their UID to the admin list. Only you can do this — it happens inside your Firebase console, which nobody else can reach.

To create a host login
1. Firebase console → Authentication → Users → Add user
2. Enter an email and password → Add user
3. Copy the new User UID from that list
4. Realtime Database → Data → admins → add that UID with value true

To change a password — Authentication → Users → ⋮ → Reset password
To revoke access — delete the UID from admins (instant, even mid-show)
Do this before every show. Your entire question bank lives in Firebase. One bad click, one wrong rule change, or one accidental project deletion and it is gone. Download a backup and keep it somewhere safe.
